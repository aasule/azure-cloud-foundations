# Azure Cloud Foundations Summary Report

## Selected Region

The selected Azure region is South Africa North. This region was chosen because it is geographically closer to Nigeria and provides lower latency for deployed resources.

## Shared Responsibility Model

For the deployed Storage Account, Microsoft Azure is responsible for securing the physical infrastructure, networking, and datacenter facilities.

The customer is responsible for:
- managing account access
- protecting credentials
- configuring permissions
- securing uploaded data

This demonstrates the Shared Responsibility Model where security responsibilities are divided between the cloud provider and the customer.
