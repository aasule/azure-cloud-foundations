## Learning Curriculum (3MTT NextGen Azure Cloud Engineering)

This repository is part of a structured learning program covering foundational to advanced Azure Cloud Engineering concepts through courses, live sessions, and hands-on labs.

---

### Cloud Fundamentals
- Introduction to Cloud Computing
- Virtualization Concepts
- Cloud Deployment & Service Models
- Cloud Pricing Models
- Benefits and Considerations of Cloud Services

---

### Azure Core Services
- Azure Resource Hierarchy
- Resource Groups and Subscriptions
- Azure Regions, Availability Zones, and Data Centers
- Azure Virtual Machines
- Azure App Service and Function Apps
- Azure Container Instances

---

### Networking & Infrastructure
- Virtual Networks (VNet), Subnets, and IP Addressing
- DNS in Azure
- Azure Load Balancer
- VPN and VPN Gateway
- Azure Firewall

---

### Storage & Databases
- Azure Storage Accounts and Tiers
- Blob Storage and Static Website Hosting
- Azure SQL Database
- Azure PostgreSQL Database
- Azure Cosmos DB
- Redis Cache

---

### Identity & Security
- Microsoft Entra ID (Azure Active Directory)
- Authentication Methods and MFA
- Conditional Access
- Role-Based Access Control (RBAC)
- Defense in Depth

---

### DevOps & Containers
- Docker Basics in Azure
- Azure Container Registry (ACR)
- API Management
- Service Bus and Queue Storage

---

### Monitoring & Management
- Azure Monitor and Alerts
- Application Insights
- Azure Advisor
- Azure Service Health

---

### Governance & Cost Management
- Azure Pricing Models and Cost Analysis
- Cost Management and Budgets
- Resource Locks, Tags, Policies, and Governance
- Azure Well-Architected Framework
- Azure Landing Zone Concepts

---

### Hands-on Projects
- Virtual Machine Deployment
- ARM Template Deployments
- Web App Deployment using App Service
- Virtual Network Configuration and Security
- Blob Storage Static Website Hosting
- PostgreSQL and Cosmos DB Deployment
- Sentiment Analysis using Azure Cognitive Services
- Cost Comparison (Azure vs AWS)
- Monitoring and Optimization with Azure Advisor

### Capstone Project
A final end-to-end cloud solution integrating multiple Azure services into a real-world architecture.
